# Erled Agency Website

A responsive single-page website for **Erled Agency**, a maritime transport and logistics company.

## Features

- Modern, responsive design built with Bootstrap 5
- Hero section with call-to-action
- About, Services, and Contact sections
- Contact form configured for Netlify Forms (or replace with your backend)
- Smooth scrolling and dynamic year in footer

## Development

No build step is required. Simply open `index.html` in your browser or deploy the folder to any static hosting provider (Netlify, Vercel, GitHub Pages, etc.).

## Deployment

1. Upload the contents of the `erled_agency` folder to your hosting provider.
2. Ensure that `styles.css` and `script.js` are in the same directory as `index.html`.
